08

Recommendations

01

HIGH Unify judge model defaults → single source of truth

All three evaluation paths (dataset_eval.py, evaluate.py, feedback_loop.py) read from ollama_model_presets.py::DEFAULT_JUDGE_PRESET. Remove hardcoded model strings; add validation that the resolved model exists before running.

02

HIGH Add pre-flight VRAM checker before training

Check available CUDA VRAM against estimated model+LoRA memory before starting train.py. Use pynvml or torch.cuda APIs. Fail fast with estimated vs available: "Need 6.2GB, only have 4.8GB".

03

HIGH Fix absolute paths in export/evaluate

Replace hardcoded /home/athar/.unsloth/llama.cpp/build/bin/llama-server with a search path + configurable LLAMA_CPP_DIR env var. Add which llama-server as fallback. Same for all convert_lora_to_gguf.py path lookups.

04

HIGH Add inter-stage state tracking (checksums)

Implement content-addressable stage outputs with SHA256 checksums. Skip re-execution when input checksums match previous run. Store in a single .pipeline/db.json or migrate to Supabase.

05

MED Remove orphaned code or add CLI paths

Options: (a) Archive generate_workflow_dataset.py and compare_quality_gates.py to a archive/ directory. (b) Add ucore generate-workflow and ucore compare-quality-gates subcommands. Remove unreachable OpenAIGenerator / AnthropicGenerator classes.

06

MED Wire feedback loop gap detection

The identify_weak_concepts() function in feedback_loop.py is a stub. Implement actual win-rate analysis per category, quality score threshold checks, and violation pattern detection. The stub returns empty lists.

07

MED Create missing preset files

Generate fast-0.5b.yaml (for 0.5B models like Qwen3-0.5B) and quality-1.7b.yaml (for thorough 1.7B training). Add validation that referenced presets exist before training starts. Create or remove premium-8b.yaml reference in dashboard.

08

MED Add post-generation dataset validation hook

After generate_dataset.py completes, run a structural validation: check JSONL parseability, required fields presence (messages/role/content), minimum row count > 0, no null bytes. Fail fast before sanitize stage.

09

LOW Connect dashboard ↔ pipeline data flow

Bridge .runtime/registry.json and .pipeline/run_manifest.json via a shared schema. Either have the dashboard poll pipeline state or have the pipeline emit structured events the dashboard consumes.

10

LOW Centralize parameter-registry.yaml validation

Write a script that validates all params in parameter-registry.yaml against actual usage in code. Add ucore validate-params subcommand. Consider generating TypeScript types and Python dataclasses from the registry.
